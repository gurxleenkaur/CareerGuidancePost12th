# 🎓 Career Guidance After 12th

A Machine Learning-based Career Guidance System that helps students discover suitable career paths after completing Class 12 based on their academic background, interests, aptitude, and career preferences.

---

## 📌 Overview

Choosing the right career after 12th can be overwhelming for students. This project uses Machine Learning to recommend suitable career options by analyzing various student attributes such as:

- Academic Stream
- 12th Percentage
- Interest Domain
- Aptitude Score
- Career Interest

The system predicts the most suitable career path and provides guidance to help students make informed decisions.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/gurxleenkaur/CareerGuidancePost12th.git
```

### Navigate into the project

```bash
cd CareerGuidancePost12th
```

### Install dependencies

```bash
pip install -r requirements.txt
```

```bash

```
